# Hotel Management System

**HMS** — это простое веб-приложение для управления отелями, клиентами и бронированиями. Проект позволяет администраторам: 
- добавлять информацию о клиентах и отелях; 
- удалять информацию о клиентах и отелях; 
- а также управлять бронированиями (добавлять, отменять); 

Приложение построено с использованием `Node.js`, `Express` и `SQLite`, что обеспечивает простоту развертывания и использования.

## Описание проекта

**Hotel Management System** решает проблему управления отелями и бронированиями, предоставляя интуитивно понятный интерфейс для администраторов. Основные возможности:
- Добавление, удаление и просмотр клиентов.
- Добавление, удаление и просмотр отелей.
- Создание и отмена бронирований.
- Проверка доступности номеров в реальном времени.

Концептуально проект предназначен для администраторов отелей, которые хотят упростить процесс управления клиентами и бронированиями.

## Установка и запуск

### Требования
- Node.js (версия 14 или выше)
- npm (версия 6 или выше)

### Шаги установки
1. Клонируйте репозиторий:
   ```bash
   https://github.com/grxxnzzz/usm_teza-de-an.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd usm_teza-de-an
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите сервер:
   ```bash
   npm start
   ```
5. Откройте браузер и перейдите по адресу `http://localhost:3000`.

## API

### Клиенты
- **POST /api/clients**: Добавить нового клиента.
  - Параметры: `name`, `contact`.
- **GET /api/clients**: Получить список всех клиентов.
- **DELETE /api/clients/:id**: Удалить клиента по ID.

### Отели
- **POST /api/hotels**: Добавить новый отель.
  - Параметры: `name`, `location`, `free_rooms`.
- **GET /api/hotels**: Получить список всех отелей.
- **DELETE /api/hotels/:id**: Удалить отель по ID.

### Бронирования
- **POST /api/bookings**: Создать новое бронирование.
  - Параметры: `client_id`, `hotel_id`, `rooms_booked`.
- **GET /api/bookings**: Получить список всех бронирований.
- **DELETE /api/bookings/:id**: Отменить бронирование по ID.

## Примеры использования

### Добавление клиента
1. Откройте страницу `http://localhost:3000`.
2. В разделе "Клиент" введите имя и контактные данные.
3. Нажмите "Добавить".

### Создание бронирования
1. Выберите клиента и отель из выпадающих списков.
2. Укажите количество номеров.
3. Нажмите "Забронировать".

### Отмена бронирования
1. Перейдите на страницу `http://localhost:3000/delete`.
2. В разделе "Бронирования" найдите нужное бронирование.
3. Нажмите "Отменить".
